Sarfeh 0.4.0 is the first release under the new name. It adds what you actually paid, who spent it and budgets, a
public price page that stays current, and a read-only demo mode.

## The name

FinOps agent is now **Sarfeh** (صرفه). The command is `sarfeh`; `finops-agent` still works as another name for it.
The install folder, the Docker project and the image names don't change, so your data stays where it is.

## Added

- **Spend.** Record what you paid each month, by hand, from an invoice or from a CSV of your history. On the 1st, the
  confirmed setup is priced and kept as that month's estimate, and gaps over 10% between paid and estimated are
  flagged.
- **Owners and budgets.** Give resources, servers and payments a team and see each team's cost every month. Set a
  budget for the organization and each team, and get an alert by email or Bale at 80% and 100%, or when a month jumps.
- **A public price page** at [pendarsolutions.ir/sarfeh/prices](https://pendarsolutions.ir/sarfeh/prices/): one server
  size at every provider, cheapest first, read twice a day from each provider's page, with the source and the date.
- **Demo mode** (`DEMO_MODE=true`) for an installation of its own: visitors land in a sample workspace without
  signing in, and nothing can be changed.

## Fixed

- **IranServer** prices were read with CPU and memory swapped after its page reordered its columns.
- **Chabokan's** cheapest plan was missing, and its closed Mashhad plans no longer count as expected.
- **MobinHost** plans with no capacity left count as sold out.

## Upgrade

```bash
sudo finops-agent upgrade
```

It backs up first, then moves to 0.4.0 and keeps your settings and data. From then on the command is also `sarfeh`.
From 0.2.0 or earlier, run the installer:

```bash
curl -fsSL https://github.com/{{REPO}}/releases/download/v{{VERSION}}/install.sh | sudo bash
```

The full list of changes is in the [changelog](https://github.com/{{REPO}}/blob/v{{VERSION}}/CHANGELOG.md).
