Sarfeh 0.6.0 stops every server from reading the providers' sites on its own. Pendar reads them twice a day, signs
the result, and publishes it on Sarfeh's price service, with one mirror in Iran and one outside. Your installation
checks every hour, tells you when new prices are out, and uses them when you say so.

## Changed

- **Prices come from Sarfeh's price service.** The installation takes a token when it's installed (or upgraded),
  looks every hour, and when new prices are out, admins see it at the top of the dashboard and get it by email and
  Bale where those are set up. To use them: **Catalog → Update prices**, or on the server:

  ```bash
  sudo sarfeh prices            # where prices come from, and whether new ones are out
  sudo sarfeh prices update     # start using the newest prices
  ```

  To have new prices applied as soon as they're out: `sudo sarfeh config set PRICE_AUTO_UPDATE=true`.
- **No price is taken on trust.** Every catalog is signed with Pendar's key and checked against the public key built
  into Sarfeh before a single row is used, whichever mirror it came from. An older catalog is refused too, so prices
  can't be rolled back.
- **What the service gets from you:** a token and your Sarfeh version. Nothing about your servers, costs or people.
  If it can't be reached, the prices you have stay, and it tries again every hour.
- A price move the guardrails would hold (more than 25% at once) is checked by hand at Pendar before it's published,
  so your installation applies it with the rest instead of asking you to approve it again.

## Added

- **Today's prices from the first start.** This release carries the catalog of 24 November 2026, with every provider
  read that day, ArvanCloud's included. A new installation starts with it; an upgraded one applies it on its first
  start after the upgrade.
- The service's API is documented, with curl examples:
  [docs/price-service-api.md](https://github.com/{{REPO}}/blob/v{{VERSION}}/docs/price-service-api.md).

## Reading the prices yourself instead

```bash
sudo sarfeh config set PRICE_SOURCE=scrape
```

The server then reads the providers' pages twice a day, as before, and never contacts the price service
([docs/price-service.md](https://github.com/{{REPO}}/blob/v{{VERSION}}/docs/price-service.md)).

## Upgrade

```bash
sudo sarfeh upgrade
```

It backs up first, then moves to 0.6.0 and keeps your settings and data. On 0.3.x the command is still called
`finops-agent` (`sudo finops-agent upgrade`); from 0.2.0 or earlier, run the installer:

```bash
curl -fsSL https://github.com/{{REPO}}/releases/download/v{{VERSION}}/install.sh | sudo bash
```
