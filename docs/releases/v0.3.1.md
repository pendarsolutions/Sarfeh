FinOps agent 0.3.1 fixes background jobs on 0.3.0 installations and lets you delete an inventory.

## Fixed

- **Price updates and server collection work again.** On 0.3.0, "Update now" under Integrations returned an error,
  and background jobs failed, because the image picked up a new release of the queue library that needs a package it
  doesn't install. Every dependency is now locked, and every change is checked by running a job through the worker.
- **Delete an inventory** with the Delete button above it. Deleting the sample workspace also removes its sample
  engineer day rate, so you start over cleanly.
- **The sample workspace speaks your language:** a Persian name and a plain explanation, instead of a developer's
  note in English.
- **100% confidence** on the review page shows in full inside its ring.

## Added

- `sudo finops-agent doctor` checks that the background worker answers.

## Upgrade

```bash
sudo finops-agent upgrade
```

It backs up first, then moves to 0.3.1 and keeps your settings and data. From 0.2.0 or earlier, run the installer:

```bash
curl -fsSL https://github.com/{{REPO}}/releases/download/v{{VERSION}}/install.sh | sudo bash
```

The full list of changes is in the [changelog](https://github.com/{{REPO}}/blob/v{{VERSION}}/CHANGELOG.md).
